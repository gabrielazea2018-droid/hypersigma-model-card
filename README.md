# HyperSIGMA - Modelo Fundacional de Inteligencia Hiperspectral

HyperSIGMA es el primer modelo fundacional a escala de mil millones de parámetros diseñado específicamente para la interpretación de imágenes hiperspectrales (HSI). Utiliza una arquitectura basada en Vision Transformer e introduce un novedoso mecanismo de atención de muestreo disperso (SSA) para promover eficazmente el aprendizaje de diversas características contextuales. Integra características espaciales y espectrales mediante un módulo de mejora espectral especialmente diseñado. Pre-entrenado con el dataset HyperGlobal-450K (aproximadamente 450,000 imágenes hiperspectrales), HyperSIGMA demuestra versatilidad y capacidad representativa superior en tareas de alto nivel (clasificación de imágenes, detección de objetivos, detección de anomalías, detección de cambios) y tareas de bajo nivel (unmixing espectral, eliminación de ruido, super-resolución).
