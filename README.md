# HyperSIGMA - Hyperspectral Intelligence Comprehension Foundation Model

HyperSIGMA is the first billion-level foundation model specifically designed for hyperspectral image (HSI) interpretation. It is a vision transformer-based architecture that unifies HSI interpretation across tasks and scenes, scalable to over one billion parameters. HyperSIGMA introduces a novel sparse sampling attention (SSA) mechanism to effectively promote the learning of diverse contextual features, and integrates spatial and spectral features using a specially designed spectral enhancement module. Pre-trained on the large-scale HyperGlobal-450K dataset (approximately 450,000 hyperspectral images), HyperSIGMA demonstrates superior versatility and representational capability across high-level tasks (image classification, target detection, anomaly detection, change detection) and low-level tasks (spectral unmixing, image denoising, image super-resolution).
